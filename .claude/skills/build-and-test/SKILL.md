# Build & Test QualDriller

## When to Use

Whenever you need to build the app, run its test suite, or verify a change
compiles, in this repo specifically. Use this instead of guessing
`xcodebuild` flags or defaulting to an iOS Simulator test destination —
running tests on an iOS Simulator does not work on this machine (see below).

## How It Works

The project is generated by XcodeGen from `project.yml`.
`QualDriller.xcodeproj` and `Info.plist` are gitignored build artifacts —
never hand-edit them; edit `project.yml` and regenerate.

**1. Always regenerate after touching `project.yml`:**

```bash
xcodegen generate
```

**2. Run tests — macOS destination, not iOS Simulator:**

```bash
xcodebuild test -scheme QualDrillerTests -destination 'platform=macOS'
```

`QualDrillerTests` is deliberately a **macOS** bundle target, not iOS. This
machine's CoreSimulator install is out of step with the installed Xcode, so
booting an iOS Simulator to run tests fails here. The test target sidesteps
that by compiling the two pure-logic files (`Ammo.swift`, `TaskList.swift` —
Foundation-only) directly into a macOS test bundle, which needs no
simulator at all.

Do not pass `-destination 'platform=iOS Simulator,...'` to the test action —
it will fail on this machine for environment reasons unrelated to the code.

**3. Verify the app target still compiles** (targeting the simulator SDK
works even though booting a simulator does not):

```bash
xcodebuild build -scheme QualDriller -destination 'generic/platform=iOS Simulator'
```

## Examples

**After changing `DrillEngine.swift`:**

```bash
xcodegen generate
xcodebuild build -scheme QualDriller -destination 'generic/platform=iOS Simulator'
xcodebuild test -scheme QualDrillerTests -destination 'platform=macOS'
```

The build confirms the app target still compiles; the test run confirms the
pure-logic files `DrillEngine` depends on (`Ammo.swift`, `TaskList.swift`)
still behave correctly.

**After adding a new Foundation-only logic file you want unit-tested:**

Add it to `Sources` under the `QualDriller` target in `project.yml` as
normal, AND add it explicitly under the `QualDrillerTests` target's
`sources` list (see how `Ammo.swift`/`TaskList.swift` are listed there) —
otherwise it will not be compiled into the test bundle. Then run
`xcodegen generate` and re-run tests.
