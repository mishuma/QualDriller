# QualDriller task list
#
#   <command text> | <par seconds> | <shots>
#
#   par    a number, or "-" for "time it but don't score it"
#   shots  a positive integer, or "mag" (until the magazine in the gun runs
#          dry). Omitted = 1.
#
# Every shot is you SHOUTING — "bang", "rack", whatever. The app hears loudness,
# never words, so it cannot tell a shot from a rack and does not try to.
#
# "mag" ends the string when the magazine runs dry, so there is no reload in a
# "mag" drill. If a drill is "empty it, reload, keep shooting", give it the
# total count instead — see 5 and 7 below.
#
# Shot counts are NEVER guessed from the text. This list is full of decoy
# numbers ("7 yards", "you have six seconds", "15 yards"), so the count is
# always explicit.
#
# ---------------------------------------------------------------------------
# COUNTS THAT SPAN A RELOAD DEPEND ON YOUR MAGAZINE SETTINGS.
#
# Drills 5 and 7 used to be "*" (open ended), which meant the timer had no idea
# when you were finished and the drill could not pass or fail. They now carry
# real counts, worked out from the default magazines: 10 / 10 / 1.
#
#   5.  10 in the gun, reload, 2 more            = 12 shots
#   7.  10 + 10 + 1, everything you have         = 21 shots
#
# Two consequences worth knowing:
#
#   * Change the magazine capacities in Settings and these two numbers are
#     wrong. Recompute them here.
#   * Both assume you START the drill with a full magazine. Ammunition carries
#     over between drills, so if you have already shot 1-4 the count is short.
#     Press REFILL in the queued state before 5 and before 7.
#
# The reload itself is NOT a shot. Shout to reload when the gun runs dry and it
# is counted as the reload, not as one of the numbers above.
# ---------------------------------------------------------------------------
#
# Blank lines and lines starting with # or // are ignored.
# Replace this file from inside the app: Settings > Import a task list.
