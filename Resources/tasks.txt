# QualDriller task list
#
#   <command text> | <par seconds> | <shots>
#
#   par    a number, or "-" for "time it but don't score it"
#   shots  a positive integer, or "mag" (until the magazine in the gun runs
#          dry). Omitted = 1.
#   reload an OPTIONAL fourth field, a magazine loadout like "10/10/1",
#          applied when that drill is queued. Use it where the course of fire
#          says to re-load differently for the next stage.
#
# "*" (open ended) is still parsed but is not used here: a string with no
# expected count cannot stop the timer or be scored, because nothing knows when
# you finished.
#
# THE COURSE OF FIRE IS STAGED:
#     Drills 1-7   start on 10/10/5 (Settings > Ammunition)
#     Drill 8      re-loads to 10/10/1 and the rest run on that
#
# Ammunition carries over between drills, so a count that spans a reload is
# arithmetic on what is left, not on a full magazine:
#     5.  drills 1-4 use 4 rounds, so 6 left in the gun, reload, 2 more  = 8
#     7.  whatever is still on the belt at that point                    = 10
# Change the loadouts and both are wrong. Recompute them here.
#
# 12 is "mag" on purpose: "fire until empty" ends when the magazine runs dry
# whatever is in it, so it needs no arithmetic and cannot go stale.
#
# The reload shout is NOT one of the counts -- while the gun is dry it is read
# as the reload, not as a shot.
#
# Shot counts are NEVER guessed from the text. This list is full of decoy
# numbers ("7 yards", "you have six seconds", "15 yards") and several drills
# have no knowable count, so the count is always explicit.
#
# Blank lines and lines starting with # or // are ignored.
# Replace this file from inside the app: Settings > Import a task list.
